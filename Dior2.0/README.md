# DIOR 2.0 — digital fashion editorial

An **unofficial student portfolio concept**. Not affiliated with or endorsed by Christian Dior SE. No products are sold. Existing fashion imagery is used solely for student demonstration; verify rights before public publication.

## Run it locally

1. Unzip the folder.
2. From inside `Dior2.0`, run `python -m http.server 8000`.
3. Open `http://localhost:8000` in your browser.

No npm, build step, frameworks, API keys, accounts or dependencies required.

## What works
- Six linked pages, sticky navigation, keyboard-accessible mobile menu and site search
- Interactive 3D magazine with next/previous, chapter jump, keyboard arrows and swipe; simplified mobile mode
- Category filter and saved favourites (stored only in your browser with localStorage)
- Fragrance mood selector with accessible tabs
- Contact form validates inputs and prepares an email in the visitor's email app; configure `CONTACT_EMAIL` in `assets/script.js` before use
- Responsive layout, focus indicators, reduced-motion handling, alt text and semantic markup

## Before showcasing professionally
- Replace the placeholder email in `assets/script.js` with your own.
- Replace imagery with photos you own or have permission to publish, or obtain appropriate permissions.
- This is an editorial UI/UX prototype, **not** a functional store, brand affiliation or secure message backend.
- Attribute group versus personal contributions accurately in your portfolio case study.
